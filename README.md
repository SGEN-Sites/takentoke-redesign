# Take N' Toke: redesign preview

A design preview for **Take N' Toke**, the licensed adult-use cannabis dispensary at 994 Atlantic Avenue, Brooklyn, NY.
Live site: https://takentoke.com. This preview is not the live site, and every page carries `noindex`.

## Concept: Neon Launch Deck

Glassmorphism, synthwave and techno, kept clean and modern, built on the brand's own identity:

- **Brand kept:** the TNT logo, the midnight indigo, cyan, neon green and purple palette, and the brand typefaces
  (Orbitron, Rajdhani, Inter, Instrument Serif). The rocket, Brooklyn rooftop and nebula artwork is the brand's own.
- **Synthwave:** a striped sun setting behind a Brooklyn skyline over a moving neon grid, in the brand's green and cyan.
- **Glass:** frosted panels only where they frame something: the header and mega menus, fact panels, cards over art.
- **Depth:** framed images and panels cross from one section into the next (anchored to their section, nothing floating).
- **Motion:** scroll reveals, a scroll-linked sunrise, parallax inside frames, card tilt and sheen on hover, a live
  New York clock, a radar sweep, and a moving hero built from the brand's rocket artwork. Every animation stops for visitors
  who ask their system for reduced motion.

## Content

Every page of the live site (70 pages: neighborhoods, landmarks, learn guides, blog, products, visit and legal pages)
is carried over with its own wording, title, description and canonical address. Dash punctuation is normalised to
commas and colons; no words were changed. The live menu is a Dutchie storefront, so menu and category filter links
open the live menu.

Images marked **AI illustration** were generated for this preview (scenes, still lifes and textures). None of them
shows a real person, a real product label or the store itself, and each can be swapped for the client's own photography.

## Files

Plain static HTML, CSS and JavaScript with no framework and no runtime dependencies. Every link is relative, so the
site runs from any folder or host.
